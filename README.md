# Кубик · Заказы

Windows-программа для поиска, оформления и выдачи заказов KubikERP.

## Установка

Скачайте KubikPickup.exe из последнего релиза и запустите. Установка выполняется для текущего пользователя Windows, с ярлыком на рабочем столе и автозапуском. На новом ПК требуется отдельная привязка к ERP.

## Работа

Слева расположены поиск и миниатюры заказов, справа — фото, комментарий, упаковка, багет, оплата и выдача. Окно изменяет размер и разворачивается. Закрытие сворачивает программу в трей. Полный выход доступен через меню трея.

## Обновления

Нажмите номер версии или выберите проверку обновлений в меню трея. После подтверждения программа проверяет подпись и контрольную сумму, устанавливает новую версию и перезапускается. Проверка не требует входа в GitHub. Привязка сохраняется для того же пользователя Windows.

Установщик пока не имеет сертификата издателя Authenticode. Windows может показывать предупреждение при первой установке. Подпись канала обновлений проверяется самой программой.

## Liquid Glass 2.1

Новый интерфейс использует [Glisse](https://github.com/0kzh/glisse) (MIT) и Microsoft Edge WebView2. Компоненты и файлы интерфейса включены в программу. На ПК нужен WebView2 Runtime. При недоступности нового интерфейса программа открывает обычное окно. Ключ устройства и подпись запросов обрабатываются в Windows-части приложения.
